# Security Policy

Security fixes target the latest Ravyn release.

Reports involving Native Messaging, local API authentication, download URL validation, path traversal, archive extraction, component provisioning, update signing, browser permissions, file deletion, installer behavior or privilege boundaries are especially important.

Please use GitHub private vulnerability reporting when available. Do not publish exploit details, tokens, private paths, cookies, credentials or sensitive logs in a public issue.

When sharing diagnostics, remove personal paths, URLs containing secrets and unrelated machine information.
