# Support

For bug reports, include:

- the Ravyn version;
- Windows version/build, or backend operating system when relevant;
- the download type involved (HTTP, media, torrent, browser integration, post-processing);
- reproduction steps;
- expected behavior;
- actual behavior;
- sanitized logs only when they materially help.

Never include cookies, API tokens, private URLs, credentials or unrelated personal paths.

For feature requests, describe the workflow you want to improve and any compatibility or security constraints you already know about.
